Sistema web para gerenciamento de pedidos em restaurantes, desenvolvido em equipe como Projeto Integrador do 1º ano do curso Técnico em Desenvolvimento de Sistemas do SENAI.

## Sobre o projeto

O Comanda Menu foi desenvolvido com o objetivo de facilitar o gerenciamento de pedidos e mesas em restaurantes.

O sistema conta com uma interface para realização de pedidos e uma área administrativa para gerenciamento de mesas, pedidos, categorias e alimentos.

## Funcionalidades

- Realização de pedidos por mesa
- Seleção de categorias e alimentos
- Gerenciamento de mesas
- Criação e acompanhamento de pedidos
- Visualização dos itens e valores do pedido
- Remoção de itens do pedido
- Cadastro e gerenciamento de alimentos e categorias
- Área administrativa

## Tecnologias

- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Minha participação

Atuei como **desenvolvedor Front-end**, sendo responsável pela criação e implementação das principais interfaces e fluxos de interação do sistema.

Também contribuí com o **Back-end**, trabalhando com PHP, integração com o banco de dados MySQL e funcionalidades relacionadas ao gerenciamento de pedidos, mesas e dados do sistema.

## Contexto acadêmico

Projeto desenvolvido durante o **1º ano do curso Técnico em Desenvolvimento de Sistemas do SENAI**, como parte do Projeto Integrador.

O projeto teve como objetivo aplicar na prática os conhecimentos adquiridos durante o curso, envolvendo desenvolvimento web, banco de dados, trabalho em equipe e desenvolvimento de uma solução para uma necessidade real.
